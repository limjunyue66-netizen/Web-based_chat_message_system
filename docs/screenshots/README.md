## Capture your own

1. Start Apache + MySQL and import `database/database.sql`.
2. Open the app in Chrome or Edge.
3. Capture Home, Login, Chat, and Admin.
4. Overwrite the files in this folder with the same names (or update `README.md` links).

Do not include production URLs, real emails, or personal account passwords in screenshots.
